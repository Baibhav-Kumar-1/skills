# Felix 2D Tech Illustrations Skill

A specialized AI Agent skill for converting complex technical concepts, GTM engineering workflows, mental models, and software architectures into clean, vibrant **flat 2D vector illustrations** featuring **Felix — The 2D Tech Architect**.

---

## ⚡ Quick Workflow

```
[1. Extract Cognitive Anchors] ➔ [2. Formulate 2D Shot List] ➔ [3. Assemble Prompt] ➔ [4. QA & Generate]
```

### Step 1: Extract Cognitive Anchors
Identify 3-6 key moments in the article:
- Old manual ops vs modern GTM engineering
- Code automation leverage multipliers
- Signal data enrichment pipelines
- Product telemetry to revenue growth bridges

### Step 2: Formulate the 2D Shot List
For each moment, define:
- **Placement**: Article section reference
- **Pattern**: *Split Screen*, *Scale Balance*, *Pipeline Flow*, or *The Bridge*
- **Felix's Action**: Felix standing/stepping confidently in a 2D vector space
- **Flat Color Callouts**: Indigo, Mint, and Coral Red text/diagram notes

### Step 3: Construct Image Prompt
Use the template from `references/prompt-template.md`:

> `16:9 clean modern 2D flat vector illustration on light off-white background (#F8FAFC). Main character "Felix": handsome dashing 2D tech architect with short stylish dark hair, glasses, casual navy jacket over white shirt. Felix is standing confidently, [FELIX_ACTION] with [2D_DIAGRAM_METAPHOR]. Vibrant flat 2D colors: Indigo Blue (#3B82F6), Mint Emerald (#10B981), and Coral Red (#F43F5E). Minimalist tech editorial illustration style, flat 2D vector art, crisp outlines, zero 3D gradients, no realistic render.`

### Step 4: QA Checklist
- [ ] Horizontal 16:9 format
- [ ] Flat 2D vector style (no 3D renders, no realistic lighting)
- [ ] Character is Felix (handsome 2D guy with glasses & navy jacket)
- [ ] Light off-white background (`#F8FAFC`) with vibrant 2D color accents
- [ ] Clean, smart, professional tech editorial aesthetic
