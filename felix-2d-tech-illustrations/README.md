# Felix 2D Tech Illustrations Skill

> An AI Agent Skill for generating clean, modern 2D flat vector illustrations for tech articles, blogs, and documentation featuring **Felix** — a handsome, intelligent 2D tech architect in a vibrant editorial style.

---

## ✨ Persona & Aesthetic Highlights

- **Character IP**: **Felix** — A handsome, smart 2D tech architect with stylish dark hair, glasses, and a casual navy jacket over a clean shirt.
- **Style**: Flat 2D vector art, clean lines, geometric diagram elements, and rich flat color blocks (Stripe / Linear / Notion editorial vibe).
- **Color Tokens**: Off-white background (`#F8FAFC`), Indigo Blue (`#3B82F6`), Mint Emerald (`#10B981`), Coral Red (`#F43F5E`), Charcoal (`#1E293B`).
- **Format**: 16:9 Widescreen Landscape.

---

## 🚀 Usage

```text
Use $felix-2d-tech-illustrations to design 4 flat 2D illustrations for my article on GTM Engineering.
```
