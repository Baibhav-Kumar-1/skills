# Style DNA — Felix 2D Tech Illustrations

## 🎨 Color Palette Tokens

| Token | Hex Code | Role |
|---|---|---|
| **Off-White Canvas** | `#F8FAFC` | Clean, light, premium editorial background. |
| **Indigo Blue** | `#3B82F6` | Primary brand color for main diagram shapes and Felix's jacket. |
| **Mint Emerald** | `#10B981` | Positive outcome nodes, growth metrics, warm intent leads. |
| **Coral Red** | `#F43F5E` | Focus callouts, high-leverage triggers, key action notes. |
| **Charcoal Outline** | `#1E293B` | Crisp 2D line work and typography. |

## 📐 Flat 2D Vector Principles
- **Strictly 2D Flat Art**: Zero 3D depth, zero realistic textures, zero volumetric lighting.
- **Clean Geometric Shapes**: Crisp circles, rounded rectangles, clean arrows, and flat color fills.
- **Generous Spacing**: 40-50% negative space on light background for clear reading.
