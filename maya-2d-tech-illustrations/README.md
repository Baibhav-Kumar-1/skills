# Maya 2D Tech Illustrations Skill

> An AI Agent Skill for generating clean, vibrant 2D flat vector illustrations for tech articles, blogs, and architecture posts featuring **Maya** — a smart, stylish, dashing female 2D tech architect.

---

## ✨ Persona & Aesthetic Highlights

- **Character IP**: **Maya** — A handsome, smart female 2D tech architect with stylish hair, glasses, and a sharp casual navy/teal blazer over a crisp white shirt.
- **Style**: Flat 2D vector art, clean lines, geometric diagram elements, and rich flat color blocks (Stripe / Linear / Notion editorial vibe).
- **Color Tokens**: Off-white background (`#F8FAFC`), Indigo Blue (`#3B82F6`), Mint Emerald (`#10B981`), Coral Pink/Red (`#F43F5E`), Warm Amber (`#F59E0B`).
- **Format**: 16:9 Widescreen Landscape.

---

## 🚀 Usage

```text
Use $maya-2d-tech-illustrations to design 4 flat 2D illustrations for my article on GTM Engineering.
```
