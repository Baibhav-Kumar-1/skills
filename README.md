# 🎨 2D Tech Illustration Skills

> A collection of open-source AI Agent Skills for generating clean, modern 2D flat vector conceptual illustrations for articles, tech blogs, and documentation (Stripe / Linear / Notion editorial style).

[![skills.sh](https://skills.sh/b/skills)](https://skills.sh)

---

## 🚀 Available Skills

| Skill | Character IP | Description |
|---|---|---|
| **[`felix-2d-tech-illustrations`](./felix-2d-tech-illustrations)** | **Felix** (Male 2D Architect) | Smart male 2D tech architect in glasses and casual navy jacket operating flat 2D vector diagrams. |
| **[`maya-2d-tech-illustrations`](./maya-2d-tech-illustrations)** | **Maya** (Female 2D Architect) | Smart white-skinned female 2D tech architect in a bold red coat (`#EF4444`), black pants, no glasses. |

---

## ⚡ Installation via `skills.sh`

Once this repository is published on your public GitHub account, anyone can install these skills using `npx skills`:

```bash
# Install Felix 2D Tech Illustrations
npx skills add <your-github-username>/<your-repo-name>/felix-2d-tech-illustrations

# Install Maya 2D Tech Illustrations
npx skills add <your-github-username>/<your-repo-name>/maya-2d-tech-illustrations
```

## 🎨 Visual Aesthetic & Palette

- **Format**: 16:9 Widescreen Landscape
- **Canvas**: Light Off-White (`#F8FAFC`) with generous 40-50% negative space
- **Palette**: Indigo Blue (`#3B82F6`), Mint Emerald (`#10B981`), Coral Red (`#F43F5E`), Charcoal (`#1E293B`)
- **Aesthetic**: Flat 2D vector shapes, geometric diagram components, clean editorial typography
